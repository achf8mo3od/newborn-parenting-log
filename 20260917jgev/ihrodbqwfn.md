# 预告│潍坊市人民医院儿童青少年过敏性疾病防治筛查公益活动

> 更新时间：2026-09-17 (UTC+8)

近年来，儿童过敏性疾病（荨麻疹、特应性皮炎、支气管哮喘、过敏性鼻炎、结膜炎以及食物过敏等）的发病率逐年增高，影响到30%以上的儿童。而且，呼吸道过敏经常被医生诊断为“感冒”“支气管炎”“慢性鼻炎”，给予不必要的抗生素等药物治疗，加重了家庭及社会的经济负担。因此，全面认识过敏性疾病，早期作出正确的诊断是对儿童过敏性疾病进行良好治疗管理、预防疾病进展及降低群众用药负担的基础。

为进一步推进我市过敏性疾病防控工作，我院与潍坊市预防医学会过敏性疾病预防与控制专业委员会联合开展过敏性疾病儿童和青少年（≤18岁）过敏原筛查、疾病预防及治疗咨询公益活动。

时间：2021年1月23日至2月27日（周一至周五）

地点：潍坊市人民医院门诊四楼过敏反应科

内容：患者接受免费的部分吸入性及食入性变应原皮肤点刺试验、疾病预防及治疗咨询等

适用人群（有以下症状中的一种或多种）：

1. 反复发作性喘息、气急、胸闷或咳嗽＞2周者；

2. 鼻痒、阵发性喷嚏、流清涕＞2周者；

3. 皮肤瘙痒、皮肤干燥＞2月者；

4. 婴儿湿疹（适用于2周岁以内儿童）者；

5. 慢性荨麻疹（病史大于6周）者。

注意事项：每周六、周日、除夕至初三（2月11日至14日）不进行该公益活动，有意来检查者可拨打0536-8192307进行预约，检查前停用抗过敏药物3天以上。来医院前请提前备好健康码，有发热症状者请先到我院发热门诊就诊。
